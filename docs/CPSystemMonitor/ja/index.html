02 / USAGE

必要な情報だけ、いつも手元に。

右クリックで表示をカスタマイズ

  • CPU・メモリ・ストレージ・ネットワークを個別にオン／オフ。
  • 各欄の履歴グラフ・最大負荷アプリも個別に切り替え。
  • コア別使用率の切り替え、標準／コンパクトの変更に対応。

シリーズ共通の操作と設定

  • 配色・背景・演出・トリガーを設定から変更。
  • 更新間隔は初期値1秒、履歴は60秒。どちらも変更できます。
  • 閉じるとトレイ／メニューバーへ格納。位置と表示設定は次回も復元。

取得範囲と権限

アプリ別のディスク・通信計測は設定の「詳細」で有効にします。Windowsでは管理者権限が必要です。取得できない最大負荷アプリ行は表示しません。ストレージの容量は選択ボリューム、最大負荷アプリは全ディスクが対象です。macOSのディスク速度は対応する物理ディスクを測定します。メモリの集計方法はOSにより異なり、VPN等では通信量が重複する場合があります。

03 / SETUP

はじめかた

  1. ZIPをダウンロードして展開

    お使いのPCに合わせてx64／ARM64を選び、フォルダ全体を展開します。

  2. CPSystemMonitor.exe を起動

    uiohook.dllはexeの隣に置いたままにしてください。

  3. 右クリックから表示と設定を変更

    自動起動は初期値オフ。設定から有効にできます。

  1. Apple silicon版のZIPを展開

    CPSystemMonitor.appをアプリケーションフォルダへ移動します。

  2. アプリを起動

    この配布版はad-hoc署名で、Appleによる公証は行っていません。配布元を確認したうえで、必要に応じてシステム設定 → プライバシーとセキュリティから初回起動を許可してください。

  3. 必要な場合だけトリガー権限を設定

    キーボード・マウストリガーを使う場合は、設定の権限案内からアクセシビリティの許可を確認します。
