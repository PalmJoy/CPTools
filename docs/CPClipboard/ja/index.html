02 // Workflow

使い方

01

Ctrlを2回で呼び出す

Alt / ⌥ + 中クリックでも開けます。トリガーは設定から変更できます。

「編集…」で文章とグループ名を編集。数字キー0〜9でグループを切り替えます。

Enterまたはクリックで元のアプリへ貼り付け。Shiftを押して選ぶとコピーだけになります。

03 // Use cases

定型文ツールの使い方・活用例

文章の登録・編集は「編集…」から。よく使う文章をショートカットで呼び出し、入力の手間を減らせます。

01

メールの挨拶・定型返信

「こんにちは、」やお礼、日程調整の文章などを定型文として登録。毎回入力せず、盤面から選んでメールやチャットへ貼り付けられます。

02

住所・署名・よく使うURL

住所、メールの署名、案内用URLなど、繰り返し使うテキストを保存。複数行の文章もそのまま登録できます。

03

仕事・個人用をグループ分け

10個のグループに用途別で整理。数字キーでグループを切り替え、上から26件はa–zのショートカットでも選べます。

04 // History

コピー履歴を検索して再利用

メニューの「履歴…」から、コピーしたテキストを新しい順に表示します。下側の検索フィルタで絞り込み、検索結果の上から26件はa–zでも選択できます。Enter・クリックで貼り付け、Shift付きならコピーだけ。

設定の「履歴」で全消去・分単位の自動消去・最大保存件数を変更できます。件数は自由入力で1000件まで。初期値は1000件、自動消去はOFFです。履歴はPC内に保存され、アプリを再起動しても残ります。

履歴ウィンドウにも「ポップアップ」の「マウスが離れたら閉じる」と距離設定が適用されます。一度カーソルをウィンドウ内に入れた後、指定した距離を超えると閉じます。

「トリガー」は編集用（定型文の盤面）と履歴用を別々に設定できます。履歴用は初期状態では無効です。OSやコピー元アプリが付けた履歴除外の印がある内容は記録しません。

05 // Setup

はじめかた

  1. zipを展開する

    CPClipboardのフォルダ一式を同じ場所に置きます。uiohook.dllはCPClipboard.exeの隣に残してください。

  2. アプリを起動する

    CPClipboard.exeを開きます。トレイのメニューから設定を開けます。

  3. 盤面を呼び出す

    Ctrlを2回押して定型文を選びます。管理者として起動したアプリには貼り付けられず、コピーだけになります。

  1. Applicationsへ移す

    zipを展開し、CPClipboard.appをApplicationsフォルダへ移してから開きます。

  2. 初回の起動を許可する

    配布物は未公証です。信頼できる入手元を確認し、「システム設定 → プライバシーとセキュリティ」から起動を許可してください。

  3. アクセシビリティを許可する

    「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でCPClipboardを許可します。未許可の間はコピーだけになります。

  4. 盤面を呼び出す

    Ctrlを2回押して定型文を選びます。

文章を登録する

トレイ／メニューバーのメニューから「編集…」を開き、グループを選んで「追加」。本文はその場で保存されます。

06 // Storage

保存とクリップボード

定型文はPC内に保存します。貼り付け後も選んだ定型文がクリップボードに残り、後からCtrl+V / ⌘Vで使えます。元のクリップボードへの復元は任意で、既定はOFFです。コピーしたテキストは履歴としてPC内に保存され、検索して再利用できます。変数やマクロ・クラウド同期はありません。
